COURSE OBJECTIVES:
------------------
1. To develop a strong foundation in advanced linear algebra techniques for analysing computing systems.
2. To understand and apply optimization methods to solve engineering and machine learning problems.
3. To gain knowledge of probability theory and statistical methods for modelling uncertainty in real-world applications.
4. To integrate mathematical concepts with computational tools to solve complex problems in data science and engineering.

COURSE OUTCOMES (COs):
----------------------
CO1: Apply advanced linear algebra concepts such as eigenvalues, orthogonality, and matrix decompositions in computing applications.
CO2: Formulate and solve optimization problems using appropriate analytical and numerical techniques.
CO3: Model and analyse random phenomena using probability distributions and statistical inference methods.
CO4: Implement mathematical methods using computational tools to solve real-world engineering and data-driven problems.

COURSE CONTENTS & MODULE STRUCTURE:
-----------------------------------

Zeroth Module: General Introduction to the Course (1 Hr)
- Course introduction with a thorough briefing of Course Objectives and Course Outcomes
- Overview of the POs that are mapped to the course

Module I: Advanced Linear Algebra for Computing (12 Hrs)
- Vector spaces, Subspaces, Basis, Dimension
- Linear transformations and matrix representations
- Eigenvalues and Eigenvectors; Diagonalization
- Singular Value Decomposition (SVD)
- LU decomposition and QR decomposition
- Iterative methods: Jacobi and Gauss-Seidel
- Least squares problems and pseudo-inverses

Module II: Optimization Techniques (12 Hrs)
- Formulation of optimization problems
- Convex sets and convex functions
- Unconstrained optimization: Gradient descent and variants, Newton's method
- Constrained optimization: Method of Lagrange multipliers
- Karush-Kuhn-Tucker (KKT) conditions

Module III: Probability Theory and Statistics (12 Hrs)
- Random variables (discrete and continuous)
- Probability distributions: Normal, Binomial, Poisson, Exponential
- Expectation, Variance, Moments
- Joint distributions and statistical independence
- Sampling methods
- Parameter estimation: Maximum Likelihood Estimation (MLE), Maximum A Posteriori (MAP)
- Hypothesis testing and Confidence intervals
- Regression analysis (linear regression)

LABORATORY EXERCISES (Minimum 8 exercises in Python):
-----------------------------------------------------
1. Introducing Python as a tool for computational mathematics
2. Introducing Python libraries (NumPy, SciPy, Matplotlib) for solving linear systems
3. Performing vector and matrix operations using Python and visualizing results
4. Solving systems of linear equations using matrix methods and visualizing solutions
5. Computing eigenvalues, eigenvectors, and Singular Value Decomposition (SVD) and visualizing applications
6. Implementing the gradient descent algorithm to solve optimization problems and visualize convergence
7. Solving optimization problems using Newton's method and visualizing results
8. Solving constrained optimization problems using Lagrange multipliers and visualizing solutions
9. Simulating random variables and probability distributions and visualizing outcomes
10. Performing hypothesis testing and regression analysis using Python and visualizing results

COURSE OBJECTIVES:
------------------
1. To introduce fundamental concepts of algorithm design, complexity analysis, and asymptotic behaviour.
2. To develop understanding of core data structures such as stacks, queues, trees, and their applications.
3. To enable the application of advanced data structures and algorithm design paradigms like Divide and Conquer and Greedy methods.
4. To analyse and evaluate graph algorithms, optimization techniques, and advanced sorting and selection methods.

COURSE OUTCOMES (COs):
----------------------
CO1: Explain algorithmic concepts, complexity measures, and asymptotic analysis techniques.
CO2: Apply fundamental data structures such as stacks, queues, and binary search trees to solve problems.
CO3: Design algorithms using advanced paradigms like Divide and Conquer and implement balanced trees and heaps.
CO4: Analyse graph algorithms and advanced techniques for solving optimization and real-world computational problems.

COURSE CONTENTS & MODULE STRUCTURE:
-----------------------------------

Zeroth Module: General Introduction to the Course (1 Hr)
- Course introduction with a thorough briefing of Course Objectives and Course Outcomes
- Overview of the POs that are mapped to the course

Module I: Introduction to Algorithm Design and Analysis (9 Hrs)
- Introduction to algorithmic thinking and characteristics of efficient algorithms
- Time and Space Complexity analysis; Asymptotic notations
- Linear-time algorithms; Maximum subarray problem
- Mathematical foundations of algorithm analysis
- Techniques for writing and proving correctness of algorithms
- Local minima problems in 1D and 2D arrays

Module II: Fundamental Data Structures (9 Hrs)
- Abstract data types (ADT)
- Range minimum query (RMQ) in 1D arrays
- Binary search trees (BST): Structure and properties, Height and balancing concepts
- Stack and queue data structures
- Expression evaluation using stacks
- Grid-based distance problems

Module III: Advanced Data Structures and Algorithmic Paradigms (9 Hrs)
- Balanced trees: Red-black trees (Height properties, Insertion, Deletion operations)
- Divide and conquer paradigm and applications: Half-majority problem, Efficient multiplication techniques
- Inversion counting
- Heap data structure and priority queues
- Dynamic data structures

Module IV: Graph Algorithms and Advanced Techniques (9 Hrs)
- Graph representations and fundamentals
- Traversal algorithms: Breadth first search (BFS), Depth first search (DFS) and DFS tree
- Bipartite graphs; Articulation points and biconnected components
- Disjoint sets (Union-Find) and set operations
- Dijkstra's shortest path algorithm
- Selection problems; Non-comparison sorting
- Range queries and multi-increment techniques
